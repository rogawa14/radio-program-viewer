# Radio Program Viewer

Windows向けの radiko 番組表ビューアです。

現在放送中の番組情報や番組詳細、放送時間、サムネイル画像を表示できます。


---

# 主な機能

- radiko 番組表取得
- 現在放送中番組表示
- 番組詳細表示
- サムネイル表示
- 放送進行バー
- ダークモード切替
- 地域切替
- 番組一覧クリック切替
- radiko再生ボタン
- 自動更新

# 使い方

1.
地域を選択

2.
放送局を選択

3.
「表示」を押す

4.
番組一覧をクリックすると詳細を切替可能

5.
「radiko再生」を押すとブラウザで再生可能

---

# 動作環境

- Windows 10 / 11
- x64

---

# 注意事項

本ソフトは radiko の公開番組表APIを利用した非公式ファンツールです。

radiko の仕様変更により動作しなくなる可能性があります。

本ソフトは録音機能を含みません。

---

# ウイルス検知について

個人開発のため、Windows Defender等で警告が表示される場合があります。

本ソフトはオープンソースであり、不要な外部通信は行いません。
